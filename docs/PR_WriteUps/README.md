# PR write-ups

One short Markdown file per reviewable change set, named `PR_<TOPIC>.md` (`SCREAMING_SNAKE_CASE`), committed with the branch and used as the pull-request description.

The format, required sections and workflow are in the [developer guide](../dev/contributing.md#pr-write-ups). The Cursor rule that asks agents to keep them current is [`.cursor/rules/pr-writeups.mdc`](../../.cursor/rules/pr-writeups.mdc).

Write-ups for earlier pilot work were removed; the merged pull requests and git history are the record.
