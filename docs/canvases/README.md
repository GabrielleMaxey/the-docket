# Cursor docs canvas (mirror)

**How to open in Cursor:** copy `task-manager-docs.canvas.tsx` from this folder into `~/.cursor/projects/<your-workspace>/canvases/`, then open that file beside chat—or ask the agent to copy it for you.

This is a **read-only mirror** for git; the live canvas must live in Cursor’s managed `canvases/` directory. Canonical docs remain in [`../DEVELOPER_GUIDE.md`](../DEVELOPER_GUIDE.md) and sibling `docs/*.md` files.
