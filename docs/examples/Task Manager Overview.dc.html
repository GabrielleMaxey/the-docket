The Daily Loop

One pass through Task Management, start to finish, without leaving the page.

1
Run JQL
Up to five saved queries load fresh from Jira.
2
Triage the table
Filter by key, status, or assignee. Sort by your priority.
3
Update in place
Status and assignee changes go straight to Jira from the row.
4
Note, then push
Notes and files save locally, then post as a Jira comment.

Refreshes, reports, and week plans keep running if you switch tabs — a status pill in the nav shows what is in progress.

Task Management

The daily driver. Everything for one issue lives in one row.

  • Per-query count chips — total, open, overdue, in progress
  • Loaded X of Y matched, with Load remaining for the rest
  • Status and assignee dropdowns that write back to Jira
  • P1–P20 personal priority, warmer row colors for P1–P3
  • Notes with up to five attachments per note
  • Closed and resolved issues are read-only

Screens redacted: project and contributor names

Notes, Priority, Push to Jira

The working layer that sits on top of Jira, and the one action that puts it back in front of the team.

P1–P20
Your own ranking, saved in the local database. A Jira badge marks a priority read from the latest comment on Run JQL.
5 files
Per note, 5 MB each — images plus TXT, PDF, DOC/DOCX, XLSX, CSV. Paste, drag, or Add file.
Push
Check the rows, click Push note. Text and attachments post as a Jira comment, visible to everyone with access.

Notes and priorities stay on your machine until you push. Nothing reaches Jira by accident.

Shared Priority Without a Spreadsheet

Teams that kept a shared Excel tracker so everyone saw the same ranking can set that ranking in the app instead.

Shared-program slot
Link a Task Management slot to a shared program. Priority saves to the team store immediately, and rows show a Team badge.
Run JQL on that slot loads priorities from the shared store. Personal slots stay local.
Bootstrap from the sheet
Export the existing tracker as CSV — Priority, ODI, Developer, Jira Status, notes — and import it in Settings.
Matching issue keys overwrite priority for the chosen target. Re-import when rankings change.

One central place to set project priorities — and the ranking sits next to the work it applies to.

Metrics

How a project is tracking, not how one issue is doing.

  • Resolved, in progress, backlog, epics complete, open past due
  • Tabs per project preset, each with its own status breakdown chart
  • Upcoming and past-due lists, grouped by project and person
  • Contributor workload and overdue counts per person
  • Snapshot stored locally — the page loads even when Jira is slow

Click any issue key or name to open Task Management already filtered to it.

Project Managers

Who is over capacity, and whether their work is actually moving.

  • Open issue count against an optional capacity target
  • Risk signals — overdue, blocked, stale at 14 days or more
  • Status and assignee breakdown per tracked entry
  • People, reporter watches, saved presets, or custom JQL groups
  • Download as .md or .csv, or Save to Reports

A raw count does not say whether work is moving. The breakdown does.

Past Reports and Chat

Everything generated is kept, and can be asked about in plain language.

Past Reports
Project reports and week plans, audience reports, saved Chat replies, and CoWork weekly-plan files — archived on this machine as they are generated.
View, copy, download, or delete. Clearing a report from a page never deletes the archived copy.
Chat
Questions answered from your preset selection, the last JQL run, the latest Metrics snapshot, and the reports already in the session.
“Which epics are past due?”
“Who has the most overdue tasks in my My Work query?”
“What did my week plan say about Tuesday?”
Outside that context it searches Jira directly, and says when it has no data rather than guessing.

Setup and Access

Runs on macOS and Windows, as a desktop app or as an installed browser window.

NOTE Some corporate laptops block the Electron desktop app. No problem — install the web UI as its own standalone app window in Chrome or Edge, same six tabs.
01
Install
Run the desktop app, or run the browser UI and install it as its own standalone window.
02
Add credentials
Jira base URL, email, and API token in the local .env file.
03
Test connection
Settings → Test Jira Connection. A check mark means everything else works.
04
Import a team pack
One JSON file of epic and JQL presets, merged or replaced. Nobody starts from scratch.
Credentials, notes, priorities, snapshots, and the report archive stay in local files on your machine — only status changes and pushed comments go to Jira.
Prefer Chrome or Edge for Install as app — the dialog shows the Task Manager name and icon, not localhost.
